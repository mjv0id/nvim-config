## nvim-config

simple neovim setup for coding, with file browsing, navigation and a minimalist theme.

> this theme was inspired by [Salar's neovim configuration](https://github.com/SalarAlo/neovim_configuration)

### plugins

- `alpha.nvim`: homepage with logo etc  
- `koda.nvim`: theme/colors
- `lazy.nvim`: plugin manager
- `mason.nvim`: development tools (LSPS etc)
- `nvim-tree`: file explorer
- `nvim-treesitter`: syntax highlighting
- `nvim-web-devicons`: file icons (.py, .lua, .md, .c, etc)
- `telescope.nvim`: file finder
- `nvim-autopairs`: automatically closes autopais like (), [], {}, "", ''
